### Core Stack

- **RFID & NFC:** MFRC522, PN532, ISO 14443A, MIFARE Classic, NTAG21x, UHF EPC Gen2
- **Hardware:** ESP32, Arduino (Uno / Nano), STM32, Raspberry Pi
- **Firmware & Code:** Embedded C/C++, Python (PySerial), PlatformIO
- **Interfaces:** SPI, I2C, UART, MQTT, REST APIs
